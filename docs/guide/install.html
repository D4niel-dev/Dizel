Install Dizel

Dizel runs from a checkout. You need Python and Node; a GPU is optional for the terminal client.

Start with v1.5. It is the published model and the one the app loads by default. The 1.6 preview has no weights yet.
npm launcher. Windows users can install the small launcher with npm install -g @d4niel-dev/dizel@latest, then run dizel install and dizel doctor. It downloads the matching release; Python and model weights remain separate.

Before you start

  • Python 3.10+ for the engine and both clients.
  • PyTorch 2.1+ — CUDA is recommended for local inference.
  • Node.js 18+ for the desktop app.
  • Windows for the dizel.cmd launcher; the Python modules also run on macOS and Linux.

Install

01

Get the code and create a virtual environment

git clone https://github.com/D4niel-dev/Dizel.git
cd Dizel

python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
02

Install the runtime

Install PyTorch for your CUDA version first, then the runtime dependencies. The desktop app installs its own npm packages on first launch.

# Example: CUDA 12.1. Use the index for your driver.
pip install torch --index-url https://download.pytorch.org/whl/cu121

pip install -r requirements.txt
03

Launch a client

cd inference/gui
npm install
npm run dev

The desktop app auto-detects a Python interpreter that can import FastAPI. Set DIZEL_PYTHON to override it.

python -m inference.tui.main \
  --checkpoint checkpoints/dizel15/dizel-v15-distill-best.pt \
  --device cuda

The TUI is keyboard-first. Type /help for commands, /skills for prompt templates, and /mcp for plugin servers.

Training only. The v1.6 path downloads the Qwen tokenizer and teacher. Put HF_TOKEN in .env at the repository root; never paste it into a notebook, a log, or a commit.
