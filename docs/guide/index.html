Docs/Overview

Dizel docs

Dizel is a local model and two clients. This guide gets you from a checkout to a running app; the model card holds the research record.

Start with v1.5. It is the published model and the one the app loads by default. The 1.6 preview has no weights yet.

What runs today

  • Dizel 1.5 — the published dense model. The desktop app, TUI, and F16 GGUF checkpoints run today.
  • Dizel 1.6 Flash — a sparse preview in pretraining. Weights and downstream benchmarks are not published.

Choose a path

  • Install Dizel — requirements and the commands to get a checkout running.
  • Launch a client — the desktop app, the terminal UI, or headless generation.
  • Read the model card — architecture, training, held-out evaluation, and limits.
  • Check releases — what is published, what is training, and the release policy.

Before you start

  • Python 3.10+ for the engine and both clients.
  • PyTorch 2.1+ — CUDA is recommended for local inference.
  • Node.js 18+ for the desktop app.
  • Windows for the dizel.cmd launcher; the Python modules also run on macOS and Linux.

If you only want to inspect the interface, open the scripted demo. No model runs in the browser.
