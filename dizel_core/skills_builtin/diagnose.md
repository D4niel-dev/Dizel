Diagnose the failure below.

- State the most likely cause in one sentence.
- Show the evidence from the error, stack trace, or code that supports it.
- Give the smallest fix, with the exact lines or commands.
- List the next two checks if the first fix does not hold.
- Ask for the missing context only if the diagnosis depends on it.
