Explain the topic below clearly.

1. Start with a one-sentence answer.
2. Build it from first principles, defining any term that matters.
3. Give one everyday analogy and one concrete example.
4. Finish with a common misunderstanding and how to avoid it.

Avoid jargon unless you define it. Keep the reply under 300 words.
