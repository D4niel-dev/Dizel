Create an outline for the material below.

- Start with a one-line thesis or goal.
- List 4–8 sections in a logical order.
- Give each section a one-line purpose and 2–3 bullet points.
- Mark where evidence, examples, or data are needed.
- End with the strongest opening and closing beats.
