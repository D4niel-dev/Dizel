Document the code below.

- Add a one-line purpose and the important parameters, returns, and errors.
- Explain why a non-obvious choice is made; do not narrate the syntax.
- Include one minimal usage example.
- Keep comments short and skip anything the code already says.
- Flag behavior that looks unintentional instead of documenting it as intended.
