Proofread the text below.

- Correct spelling, grammar, punctuation, and clear typos.
- Fix awkward phrasing only where it improves readability; keep the author's voice and meaning.
- Do not restructure or add new ideas.
- Return the corrected text first, then a short bullet list of the changes that matter.
